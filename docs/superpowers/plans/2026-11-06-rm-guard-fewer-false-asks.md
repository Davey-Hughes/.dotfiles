# rm guard: fewer false asks — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut `rm_guard.py`'s false asks, which were 673 over the real transcript corpus, by reading more of the shell it is given. Close the four holes found while designing this.

**Architecture:** Every change lives in `config/.claude/hooks/rm_guard.py`, the single-file PreToolUse guard. Each fix is a small function plus one integration point in `analyse()`, `analyse_segment()`, `classify_one()`, `classify_path()` or `proven_bindings()`. Each lands test-first in `test_rm_guard.py` and is measured against the transcript corpus (`test_rm_guard_corpus.py`).

**Tech Stack:** Python 3 stdlib only (`shlex`, `re`, `os`, `posixpath`); bash for the wrapper; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-06-rm-guard-fewer-false-asks-design.md`. Read it first; this plan does not repeat its reasoning.

## Global Constraints

- **Where to work.** Never edit the guard in `~/.dotfiles` directly. Auto mode refuses it as self-modification, and the file is symlinked live into `~/.config/.claude/hooks/`. All work happens in the scratch clone `$C` (Task 1, Step 1). The user applies the result with `git am`.
- **When the guard may stay silent.** The deletion target stays an allowlist. Anything unproven asks, and no change may turn a `deny` into anything else. Silence is allowed only for a line with no delete in it.
- **What an allow covers.** An `allow` approves the whole Bash call. Every allow stays subject to `RISKY_NEIGHBOURS` in `main()`.
- **Which suites to run.** All three suites must pass at every commit: `python3 config/.claude/hooks/test_rm_guard.py`, `python3 config/.claude/hooks/test_rm_guard_corpus.py`, and `python3 tests/test-codex-guard.py`. Run them from `$C`.
- **When the corpus fixture moves.** Any task that moves corpus verdicts reviews every moved row before running `--regenerate` (see "The corpus step" below).
- **How the hook is invoked.** `rm_guard.py --no-disk` is a command-line flag and never an environment variable. Claude Code runs the hook with no arguments.
- **No attribution.** No AI attribution in code, comments, docstrings or commit messages.
- **Shell hazards.** Never put a `\u` escape in a Write, Edit or Bash parameter, because the tool layer unescapes it. The guard's sentinels are written as `"\ue000"` in source files; type them with an editor that writes those six characters literally, or use `chr(0xE000)`. The Bash tool is zsh with `noclobber`, so write scratch scripts to new paths and run them with `bash` or `python3`.
- **Commit style.** Commit messages follow the repo's style: `fix(claude): …` / `feat(claude): …`, imperative, lower case.

## The corpus step (referenced by every task that moves verdicts)

1. **See what moved.** Run `cd "$C/config/.claude/hooks" && python3 test_rm_guard_corpus.py`. It prints one `FAIL cwd=… want X, got Y` block per moved verdict.
2. **Classify every FAIL:**
   - `ask → allow`: confirm the command really is safe under the new rule, and name the rule in the commit message.
   - `ask → silent`: allowed only for fix 1 (a line with no real delete).
   - `deny → *`, `allow → silent`, or anything else: a regression. Stop and fix it.
   - `allow → ask`: acceptable, but list it in the commit message.
3. **Regenerate.** Run `python3 test_rm_guard_corpus.py --regenerate`. It must end `wrote N commands x 3 cwds`. If it prints `REWRITE CHANGED A VERDICT`, the anonymiser and the guard disagree; fix that before going on.
4. **Confirm.** Run `python3 test_rm_guard_corpus.py` again. It must print `… corpus verdicts hold`.

def _heredoc_opener_rest(m):
    """What follows a quoted heredoc's delimiter on its OPENING line, plus the
    newline that ends that line.

    HEREDOC_RE matches from `<<` through the terminator, so replacing the whole
    match also erased the code after the delimiter: `cat <<'EOF' >/dev/null;
    rm -rf /` followed by a body was masked to `cat` and nothing else, and the
    guard went silent on it. That rest of the line runs before the body is
    read, and it goes back as code. HEREDOC_RE's `^` anchor guarantees a
    newline between the delimiter and the terminator.
    """
    start = m.end(3) + 1                  # past the delimiter's closing quote
    nl = m.string.index("\n", start)
    return m.string[start:nl] + "\n"
```

def _quiet_redirects(seg):
    """Does every redirection in seg leave its text unrunnable?

    Input redirections only read, `2>&1`-style duplications move a stream,
    and /dev/null swallows one. Anything else writes the text somewhere a
    later command could run it from. `|&` is a pipe to the shell but not a
    separator to segment_bounds, so it is refused here outright.
    """
    j = 0
    while j < len(seg):
        t = seg[j]
        if t == "|&":
            return False
        if REDIRECT_TOKEN_RE.match(t):
            target = seg[j + 1] if j + 1 < len(seg) else ""
            op = t.lstrip("0123456789")
            if op.startswith("<") and ">" not in op:
                j += 2
                continue
            if op.endswith("&") and (target.isdigit() or target == "-"):
                j += 2
                continue
            if target == "/dev/null":
                j += 2
                continue
            return False
        j += 1
    return True


def _inert_mention(toks, bounds, i):
    """Is token i text that a printing or matching command only reads?

    The backstop's question is "did a real recursive rm fail to parse?". For a
    grep pattern the answer is provably no when all of these hold: the token
    is an argument and not the command; it carries no substitution -- those
    bodies are never analysed, and the backstop is the only thing that sees an
    rm inside one; its command only prints or matches; nothing redirects it
    into a file; and everything it pipes into is another such command.
    """
    k = next((n for n, (s, e) in enumerate(bounds) if s <= i < e), None)
    if k is None:
        return False
    s, e = bounds[k]
    j, base = command_word(toks[s:e])
    if base not in INERT_READERS or s + j >= i:
        return False
    if has_subst(toks[i]) or not _quiet_redirects(toks[s:e]):
        return False
    while k + 1 < len(bounds) and toks[bounds[k][1]] == "|":
        k += 1
        s2, e2 = bounds[k]
        _, sink = command_word(toks[s2:e2])
        if sink not in PIPE_SINKS or not _quiet_redirects(toks[s2:e2]):
            return False
    return True
```

def shell_script(argv, i):
    """`SHELL [opts] -c SCRIPT ...` with the shell at argv[i] -> SCRIPT's index.

    None when this shell has no -c (it runs a file, or reads stdin). False
    when its options cannot be read, which the caller turns into the ask the
    guard has always given here.
    """
    j, saw_c = i + 1, False
    while j < len(argv) and argv[j] not in SEPARATORS:
        t = argv[j]
        if t in SHELL_VALUE_OPTS:
            j += 2
            continue
        if t == "--":
            j += 1
            break
        if t.startswith("--"):
            if t not in SHELL_LONG_FLAGS:
                return False
            j += 1
            continue
        if SHELL_FLAG_RE.match(t):
            saw_c = saw_c or (t[0] == "-" and "c" in t[1:])
            j += 1
            continue
        break
    if not saw_c:
        return None
    if (j >= len(argv) or argv[j] in SEPARATORS
            or REDIRECT_TOKEN_RE.match(argv[j])):
        return False
    return j

def shell_stdin_script(toks, bounds, k, bodies):
    """The quoted heredoc body that segment k's shell reads as its script.

    Only for a shell with no -c and nothing after it but short flags and the
    heredoc. With a script operand, stdin is that script's data, not code.
    The body arrives in the shell's own segment, or from a `cat` that does
    nothing but print it into a pipe. -> None otherwise.
    """
    s, e = bounds[k]
    seg = toks[s:e]
    j, base = command_word(seg)
    if base not in SHELLS or shell_script(seg, j) is not None:
        return None
    rest = seg[j + 1:]
    if any(t not in bodies and not SHELL_FLAG_RE.match(t) for t in rest):
        return None

    if own:
        return bodies[own[0]]
    if k > 0 and toks[bounds[k - 1][1]] == "|":
        ps, pe = bounds[k - 1]
        prev = toks[ps:pe]
        if len(prev) == 2 and os.path.basename(prev[0]) == "cat" and prev[1] in bodies:
            return bodies[prev[1]]
    return None

def inline_source(cmd, toks, cwd):
    """`. FILE; rest` leading the line -> FILE's text, a newline, then rest.

    A sourced file is code that runs in this very shell, so the honest reading
    of the line is the file's text in its place. Nothing on the line runs
    before the first command, so nothing on it can have written the file.
    Every refusal is None, and the caller asks exactly as it always did.
    """
    if NO_DISK or len(toks) < 2:
        return None
    m = SOURCE_LEAD_RE.match(cmd)
    if not m or m.group(1) != toks[1]:
        return None
    if len(toks) > 2 and toks[2] not in (";", "&&"):
        return None
    path = m.group(1)
    if "/" not in path:
        return None                   # a bare name is looked up on $PATH first
    if path.startswith("~/"):
        home = _home()
        if not home:
            return None
        path = home + path[1:]
    elif "~" in path:
        return None
    if not posixpath.isabs(path):
        if not (cwd and posixpath.isabs(cwd)):
            return None
        path = posixpath.join(cwd, path)
    real = os.path.realpath(path)
    try:
        if not os.path.isfile(real) or os.path.getsize(real) > MAX_SOURCED_BYTES:
            return None
        with open(real, "rb") as fh:
            text = fh.read().decode("utf-8")
    except (OSError, UnicodeDecodeError):
        return None
    # An allow would approve the file's commands too, so RISKY_NEIGHBOURS has to
    # see them; main() only ever sees the line. An alias rewrites what a later
    # word means, which no rule here models.
    if risky_neighbour(text) or re.search(r"(?<![\w-])alias(?![\w-])", text):
        return None
    return text + "\n" + cmd[m.end():]
```

def parse_xargs(argv, j):
    """xargs at argv[j] -> (index of the command it runs, its -I string).

    The index is len(argv) when xargs names no command, and so runs echo. The
    -I string is None when there is none. -> None when an option cannot be
    read, which the caller turns into an ask.
    """
    i, replace = j + 1, None
    while i < len(argv):
        t = argv[i]
        if t == "--":
            return i + 1, replace
        if t.startswith("--"):
            name, eq, val = t.partition("=")
            if name in XARGS_LONG_FLAGS and not eq:
                i += 1
            elif name in XARGS_LONG_VALUE:
                i += 1 if eq else 2
            elif name in XARGS_LONG_OPTIONAL:
                if name == "--replace":
                    replace = val if eq else "{}"
                i += 1
            else:
                return None
            continue
        if not t.startswith("-") or t == "-":
            return i, replace
        k = 1
        while k < len(t):
            c = t[k]
            if c in XARGS_FLAGS:
                k += 1
                continue
            if c in XARGS_VALUE:
                val = t[k + 1:]
                if not val:
                    if i + 1 >= len(argv):
                        return None
                    i += 1
                    val = argv[i]
                if c == "I":
                    replace = val
                break
            if c in XARGS_OPTIONAL:
                if c == "i":
                    replace = t[k + 1:] or "{}"
                break
            return None
        i += 1
    return i, replace
```

def _git_marker(d):
    """Is d/.git a real repository marker: a directory holding HEAD, or a file
    whose first line is a `gitdir:` pointer (a linked worktree or submodule)?"""
    g = os.path.join(d, ".git")

        if os.path.isfile(g):

def inside_work_tree(p, home):
    """-> the git work tree p sits strictly inside, or None.

    Walks up from p's parent to the first directory with a .git entry, and
    stops before $HOME, so a home that is itself a repository clears nothing.
    p must not be a work tree's top, its own or a nested one's, nor anything
    in .git. Every symlink that exists is resolved, so a link out of the tree
    does not ride its parent's verdict.

        return None
    hp = home.rstrip("/") + "/"
    if not p.startswith(hp) or os.path.lexists(os.path.join(p, ".git")):
        return None

            if not _git_marker(d) or p[len(d) + 1:].split("/", 1)[0] == ".git":
                return None
            real_tree = os.path.realpath(d)
            if not real_tree.startswith(os.path.realpath(home).rstrip("/") + "/"):
                return None
            if not os.path.realpath(p).startswith(real_tree.rstrip("/") + "/"):
                return None
            return d
        d = posixpath.dirname(d)
    return None
